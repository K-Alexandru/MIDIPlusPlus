# What a release bundles beside convert.py, pinned to the versions the owner's
# environment had on 2026-09-15. tools/make-release.ps1 installs this with
# --no-deps, so every package the converter needs is named here and nothing
# arrives by resolution.
#
# The rule for what is in: everything a real conversion, a link download and
# the sign-in window load, recorded from sys.modules over a real Transkun run
# on 2026-09-15. Transkun declares matplotlib, seaborn, pandas, tensorboard,
# ncls, sox and torch-optimizer too; a transcription never imports them (they
# are for training and evaluation), so they stay out, which is about 230 MB.
# torch declares filelock, fsspec, jinja2 and networkx; inference never loads
# them either. sympy it does load, so it is in.
#
# CPU-only PyTorch: the +cpu builds live on PyTorch's own index, and the owner's
# card is AMD, so a CUDA build would be dead weight for everyone.
--extra-index-url https://download.pytorch.org/whl/cpu
